# Reusable Widgets Layer
Folder ini berisi komponen UI kustom yang dapat digunakan kembali (minimal 3 widget sesuai ketentuan UTS):
1. `hydration_card.dart`: Kartu statistik konsumsi air dan persentase target.
2. `drink_tile.dart`: Komponen item daftar riwayat minum.
3. `water_intake_button.dart`: Tombol interaktif quick-add volume air (misal: +250ml, +500ml).
4. `custom_loading_error.dart`: Widget reusable untuk indikator loading dan error state.
