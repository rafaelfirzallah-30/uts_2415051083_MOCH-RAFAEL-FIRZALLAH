# Screens Layer
Folder ini berisi tampilan (minimal 6 screen fungsional sesuai ketentuan UTS):
1. `home_screen.dart`: Dashboard ringkasan minum hari ini & progres target.
2. `drink_list_screen.dart`: Daftar riwayat konsumsi minum (responsif list/grid).
3. `drink_detail_screen.dart`: Halaman detail data log minum.
4. `add_drink_screen.dart`: Form tambah catatan minum baru.
5. `edit_drink_screen.dart`: Form edit catatan minum.
6. `tips_screen.dart`: Halaman tips & edukasi hidrasi dari REST API.
7. `profile_screen.dart`: Halaman profil mahasiswa & pengaturan target air.
