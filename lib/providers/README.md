# Providers Layer (State Management)
Folder ini mengelola state aplikasi menggunakan `ChangeNotifier`:
- `drink_provider.dart`: Mengelola state riwayat minum, target harian, status loading, error, dan total konsumsi hari ini.
- `tip_provider.dart`: Mengelola state tips hidrasi harian dari API (loading, data, error).
- `theme_provider.dart` / `settings_provider.dart`: Mengelola preferensi pengguna dan target hidrasi.
